# 一目 Glance — IDE 风格的侧边栏标签页管理器

> 取「一目了然」：几十个标签、多窗口、多分组，一眼看全。

核心是**管理当前打开的标签页**：像 IDE 资源管理器一样的目录树（窗口 → 分组 → 标签页），覆盖 Polychrome 的全部能力（垂直标签列表、分组、多窗口、搜索、拖拽、固定标签、去重、归档）并加强：加备注、全文内容搜索、批量操作、右键菜单、键盘导航、整组恢复。

## 安装（开发者模式加载）

1. 打开 `chrome://extensions`，右上角开启「开发者模式」
2. 点「加载已解压的扩展程序」，选择本目录（`linknest/`）
3. 点工具栏 🔖 图标（或 `Cmd+Shift+L` / `Ctrl+Shift+L`）打开侧边栏

> 需要 Chrome 114+（Side Panel + Tab Groups API）。

## 「标签页」视图（核心）

IDE 目录树，实时同步所有窗口：

```
▾ 当前窗口 (12)
  ▾ ● work（分组，带颜色）
      🌐 [周报] Weekly Report - Google Docs
      🌐 JIRA Board
  🌐 掘金 - 前端周刊          ← 未分组标签
▸ 窗口 2 (5)
```

### 交互（对齐 IDE 习惯）
| 操作 | 效果 |
| --- | --- |
| 单击标签行 | 切换到该标签页（跨窗口自动聚焦） |
| 双击 / `F2` | 行内加备注 |
| `↑` `↓` `Enter` `Del` | 键盘导航 / 打开 / 关闭 |
| 右键 | 上下文菜单（收藏 / 固定 / 静音 / 移出分组 / 复制链接 / 关闭重复项…） |
| 拖到另一标签上 | 插到它前面（跨窗口、自动跟组） |
| 拖到分组头 / 窗口头 | 移入该分组 / 该窗口 |
| 单击分组头 | 折叠展开（与 Chrome 标签栏实时同步） |
| `/` 或 `Cmd+F` | 聚焦搜索框 |
| `Alt+←` / `Alt+→` | 按访问顺序后退 / 前进到上一个、下一个标签页（跨窗口） |

### 工具栏
- **← →**：IDE 式「导航后退 / 前进」——按你**实际访问的顺序**在标签页之间跳，跨窗口也行。几个常用页面来回看时，比在标签栏里找快得多。面板内 `Alt+←` / `Alt+→`；全局快捷键默认 `Alt+Shift+←` / `Alt+Shift+→`（在 `chrome://extensions/shortcuts` 可改），不开侧边栏也能用
- **🧹 清理**：清理不常用标签页——选一个时长（30 分钟 ～ 7 天，或任意），列出这么久没看过的标签页（最久的排最前，显示「N 天前」），默认全选，逐个取消勾选后确认关闭。正在看的、📌 固定的、🔊 正在出声的不会列入；误关可去「最近」视图恢复
  - **🛡 标记不清理**：确认清理时给某些页面点 🛡，按链接**永久记住**，以后每次清理自动跳过，不用再勾。右键任意标签页也能标记 / 取消，树里带 🛡 角标
- **🎯 定位**：像 IDE「在目录树中显示当前文件」——清空搜索、展开所在窗口和分组，滚动到当前标签页并高亮（打开侧边栏时也会自动定位一次）
- **🧹 N**：一键关闭重复标签页（URL 归一化比对：去 hash、utm 等跟踪参数；保留固定 / 活动 / 最近使用的那个）
- **▦**：分组菜单 — 按域名归入**面板虚拟分组**（只在侧边栏里成组，不创建浏览器标签组、标签栏不长胶囊）；取消全部面板分组；解散浏览器原生标签组（去胶囊）
- **🔍**：索引所有标签页正文（meta + 正文前 4000 字），之后搜索可命中「内容」
- **☑**：批量模式 — 勾选后底部操作栏：关闭 / 收藏 / 移入分组 / 移到新窗口
- **⊟**：全部折叠 / 展开

### 分组
- **面板虚拟分组（默认，空心圆点）**：只存在于侧边栏，不产生标签栏胶囊；按 URL 持久存储——重启浏览器、取消再重建，组名和归属都不丢。重命名、九色调色板、折叠、取消分组、整组关闭、整组收藏、拖拽入组全支持。
- **浏览器原生标签组（实心圆点）**：如果你在标签栏自己建了组，树里同样展示并可管理，与 Chrome 双向同步；插件自身不再创建原生组。

## 搜索（两个视图共用一个框）

同时匹配四个字段：**备注 / 标题 / 链接 / 内容**，多词空格分隔取 AND；结果按 备注 > 标题 > 链接 > 内容 加权；树自动过滤收敛、命中高亮、字段角标、内容命中显示上下文片段。

**加备注 ⭐**：给标签页/链接起别名（双击即起），按 URL 记忆并持久化——同一 URL 明天再打开，备注还在；标签页和收藏两边通用。长英文文档起个中文备注，搜索快人一步。

## 「最近」视图

- **🔥 高频使用**：按使用次数排序的常用页面排行（同域名同标题自动合并计数），置顶展示，每页 15 条可翻页；条目带「N 次」徽章
- **↩ 最近关闭**：刚关掉的标签页 / 整个窗口，单击或点 ↩ 一键恢复（默认折叠，点标题展开）
- **浏览历史**：按 今天 / 昨天 / 更早 分桶折叠，显示访问时间；不搜索时展示近 7 天，**输入关键词自动搜全部历史**（备注也能命中）
- **已打开的不重复开**：最近/收藏里点开链接时，若该页已有标签页则直接切换过去（收藏「整组恢复」也会自动跳过已打开的）
- 每条历史可以：⭐ 收藏（若页面开着会顺带抓正文和图标）、✎ 加备注、✕ 从历史记录删除（两步确认）、右键更多操作

## 「收藏」视图（归档）

同一套目录树交互：分组文件夹 → 链接。

- 标签页视图点 ⭐（或右键网页「收藏到一目」）即归档，自动带走备注和页面内容
- 文件夹 **↗ 一键整组恢复**：新窗口打开全部链接并自动建同名标签组（会话保存/恢复）
- 收藏时自动去重；「⋯」菜单里可一键清理历史重复、导出 / 导入 JSON
- 拖拽链接到文件夹归组；行内编辑备注 / 标题 / 描述

## 数据与权限

数据全部存 `chrome.storage.local`，不上传（标签页访问顺序存 `chrome.storage.session`，关浏览器即清）。权限：`sidePanel`（侧边栏）、`tabs`+`tabGroups`（读写标签页与分组）、`storage`（本地数据）、`scripting`+host（仅在收藏/索引时抓正文）、`contextMenus`（右键收藏）、`favicon`（网站图标）、`history`+`sessions`（「最近」视图：浏览历史与恢复最近关闭）。
